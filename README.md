# 📖 About

PrepFlow AI is an AI-powered learning platform that converts any technical topic into a structured study workspace.

Simply enter a topic such as:

- Binary Search
- React Hooks
- Dynamic Programming
- DBMS
- Operating Systems

and PrepFlow AI generates an interactive learning experience containing summaries, flashcards, quizzes, interview questions, coding examples and revision notes.

# 🚀 Getting Started

## Clone

```bash
git clone https://github.com/suhashkowsick1234/prepflow-platform.git
```

## Install

```bash
pnpm install
```

## Configure

Create a `.env`

```env
GROQ_API_KEY=your_api_key
```

## Run

```bash
node run-local.js
```

Open

```
http://localhost:3000
```
